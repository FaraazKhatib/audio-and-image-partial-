How VeriTrust Works
Stacking Ensemble
Three powerful classifiers — XGBoost, LightGBM, and Logistic Regression — are combined through a meta-learner for superior text classification.
99.6% F1-Score
TF-IDF Bigrams
Text is vectorized into 20,000-feature bigram TF-IDF space, capturing linguistic patterns invisible to simpler bag-of-words approaches.
20K features
EfficientNetV2B2
Pretrained on ImageNet, fine-tuned on 140K real/fake face images. Uses Global Max Pooling + Dropout for robust generalization.
128×128 px input
Data Augmentation
Albumentations-based augmentation — flips, rotation, brightness, gamma, random crops — makes the model robust to real-world image variations.
SMOTE balanced
